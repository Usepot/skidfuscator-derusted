    Rollout order
    
            
    Ship the changes as a ladder. Each rung should have fixture jars, bytecode verification, runtime smoke tests, and a deobfuscation regression sample.
    
          
    
        
    
        
    
          
    
            1
            
    Expose the hardened profile
    
            
    Make wide seed, compressed guard, salted fold, SDK, and silent tamper a named preset. Keep defaults conservative.
    
          
    
          
    
            2
            
    Replace XOR-only paths
    
            
    Add polymorphic int and long encoders, then route NumberManager and wide seed loaders through them.
    
          
    
          
    
            3
            
    Bind keys to sites
    
            
    Derive string, invokedynamic, and constant keys from seed plus class, method, block, literal index, and salt.
    
          
    
          
    
            4
            
    Close the mesh
    
            
    Move tamper to method-code-region hashing, allow cycles, then feed the result into flow or decrypt key derivation.
